# Desafio Técnico Frontend - Sistema de Gerenciamento de Assinaturas

Interface de usuário para consumir a API de gerenciamento de assinaturas, construída com React e Vite, seguindo o padrão visual do Life Design da T2M.

## 🚀 Tecnologias Utilizadas
- React + Vite
- TypeScript / JavaScript
- Axios (Integração de API)
- React Router Dom (Navegação e Rotas)
- React Toastify (Feedbacks visuais)
- Bootstrap / Life Design T2M (Estilização)

## ⚙️ Configuração e Execução

### 1. Variáveis de Ambiente
Crie um arquivo chamado `.env` na raiz do projeto frontend. Configure a variável com a URL da API:

```env
VITE_API_URL=https://localhost:7019/api
```

### 2. Instalação das Dependências
Abra o terminal na pasta raiz do frontend e execute:

```bash
npm install
```

### 3. Rodando o Projeto
Para iniciar o servidor de desenvolvimento:

```bash
npm run dev
```
A aplicação estará em `http://localhost:5173`.
